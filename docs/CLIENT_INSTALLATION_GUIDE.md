# Installing Shop Manager

## What you need

- A Windows computer (Windows 10 or 11).
- The `ShopManagerSetup.exe` file you were given.
- That's it — no internet connection is needed to install or use the app.

## Steps

1. Copy `ShopManagerSetup.exe` onto the shop computer (USB drive, email to
   yourself, however is convenient).
2. Double-click it.
3. If Windows shows a blue "Windows protected your PC" screen, click
   **More info**, then **Run anyway**. (This happens because the app isn't
   yet registered with Microsoft's certification service — it is safe;
   this is normal for small business software.)
4. Follow the installer prompts (Next → Install → Finish).
5. A shortcut named **Shop Manager** appears on your Desktop and in the
   Start Menu.

## First time opening the app

1. Double-click the **Shop Manager** shortcut.
2. The first time, you'll be asked to create your **username** and
   **password or PIN**. Choose something you'll remember — write it down
   somewhere safe. This protects your shop's data from anyone else who
   uses this computer.
3. After that, you'll see the Dashboard. You're ready to start adding
   suppliers, products, and purchases.

## Every time after that

Just double-click the Shop Manager shortcut and log in with your username
and password/PIN.

## Important: back up your data regularly

Since this app is fully offline, your data lives only on this one
computer. See `docs/BACKUP_RESTORE_GUIDE.md` for how to make regular
backups — do this at least once a week, and always before doing anything
risky to the computer (reinstalling Windows, giving it away, etc).

## Uninstalling

Use Windows Settings → Apps → Shop Manager → Uninstall, same as any other
program. **Back up your data first** — uninstalling does not delete your
saved database, but it's safest to have a copy before doing anything like
this.
