Icons for the Windows installer go here, generated by running:

    npx @tauri-apps/cli icon path/to/your-logo.png

from the project root. This fills in 32x32.png, 128x128.png,
128x128@2x.png, icon.icns, and icon.ico automatically from one source
image (square PNG, 512x512 or larger recommended).

This folder is intentionally left without real icon files in the
delivered source — see docs/PACKAGING.md.
